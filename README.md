## 💡 Sobre o Projeto

Este projeto foi desenvolvido como parte das entregas da SA CRUD do 1°semestre no curso no **SENAI**. O objetivo principal é fornecer uma ferramenta prática e intuitiva para que os usuários possam gerenciar suas finanças pessoais. 

Com a plataforma, é possível realizar o cadastro, registrar transações de receitas e despesas, e visualizar de forma clara o panorama financeiro por meio de **gráficos dinâmicos** e tabelas organizadas, auxiliando na tomada de decisões e no planejamento para investimentos.

## ✨ Principais Funcionalidades

* 📝 **Cadastro e Autenticação:** Área para o usuário acessar o seu painel de controle pessoal.
* ➕ **Registro de Movimentações:** Adição simplificada de receitas (ganhos) e despesas (gastos).
* 📊 **Gráficos Interativos:** Visualização visual da distribuição financeira para facilitar a compreensão dos hábitos de consumo.
* 📋 **Tabela de Gastos:** Listagem detalhada de todas as transações realizadas.
* 📱 **Design Responsivo:** Interface adaptada para diferentes tamanhos de tela (computadores e celulares).

---

## 🧰 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

* **HTML5 / CSS3:** Estruturação e estilização das páginas com design moderno.
* **JavaScript (ES6+):** Lógica da aplicação, manipulação do DOM e interatividade.
* **Vercel:** Hospedagem e deploy contínuo da aplicação.
